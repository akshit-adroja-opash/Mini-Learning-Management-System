# Walkthrough Script

Use this file to outline the final 5-8 minute video walkthrough.

## Suggested Flow

1. Login as each role.
2. Instructor creates a course with modules, video lessons, reading materials, and quiz.
3. Learner browses catalog and enrolls.
4. Learner watches a video, refreshes, and resumes from saved progress.
5. Lesson completes after at least 90 percent watched.
6. Learner passes module quiz and unlocks next module.
7. Learner completes course and views certificate.
8. Certificate verification URL is tested.
9. Instructor reviews analytics and discussion thread.
